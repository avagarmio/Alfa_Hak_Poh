# Настройка систем-потребителей

Контроль доступа включается флагом `auth_enabled: true` в `config/systems.json` (или переменной окружения `AUTH_ENABLED=true`), и по умолчанию он выключен — тогда обрабатываются все запросы с маскированием всех типов. Чтобы добавить систему, впишите её идентификатор в объект `systems` и передавайте его в заголовке `X-System-ID`; незарегистрированная или отключённая (`enabled: false`) система получает `403`. Список типов ПД для маскирования задаётся в `mask_types` (пустой список = маскировать все типы; допустимые значения: `FIO`, `PHONE`, `EMAIL`, `PASSPORT`, `PASS_CODE`, `PASS_AUTHORITY`, `DATE`, `DRIVER`, `INN`, `CARD`, `CVV`, `PIN`, `CARD_HOLDER`, `ADDRESS`, `BIRTHPLACE`, `CITIZENSHIP`). Демаскирование для системы включается/выключается флагом `demask_enabled`: при `false` обратный шаг возвращает присланную строку без восстановления оригинала. Путь к файлу настроек можно переопределить переменной `CONFIG_PATH`.
